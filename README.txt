OpenWithLove Anniversary A1

CUSTOMIZE AN ORDER
1. Open config.js. The browser-tab title, customer names, date, passcode,
   wording, letter text, reasons, photo paths/captions, and music path are
   grouped in that file.
2. Replace the sample values in config.js. Keep the quotes, commas, and square
   brackets, and keep the passcode inside quotes.
3. Copy customer photos into sample-photos and update the matching paths in
   config.js. Photo keys cover the opening screen, question, letter, gifts,
   gallery, and reasons page.
4. Copy the customer's music file into music and update music.src in config.js.
   Visitors can start or pause it with the music button; browsers require a
   click before they will play audio.
5. Keep index.html, config.js, sample-photos, and music together. Open index.html
   in a browser to preview the page. If audio does not play from a file:// URL,
   preview it through your website host or a local web server instead.

The included photos and music are sample assets. The passcode is set in
config.js. This is a front-end surprise page, not secure authentication.
